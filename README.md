# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

# Планировщик задач

## Описание проекта

Проект представляет собой HTTP-сервис для планирования задач. Он позволяет добавлять, просматривать, отмечать задачи выполненными и удалять их. Также реализована поддержка повторяющихся задач с логикой автоматического переноса даты выполнения.

## Выполненные задания со звёздочкой

Задания повышенной сложности **не выполнялись**.

## Как запустить проект локально

### 1. Установите зависимости

```bash
go mod tidy
```

### 2. Запустите сервер

```bash
go run ./cmd/main.go
```

Сервер будет доступен по адресу:

```
http://localhost:7540
```

### 3. Примеры запросов

Добавить задачу:

```bash
curl -X POST http://localhost:8080/api/task   -H "Content-Type: application/json"   -d '{"title": "Позвонить маме", "date": "20250801", "repeat": "d 2"}'
```

Посмотреть задачу:

```bash
curl http://localhost:8080/api/task?id=<ID>
```

Отметить задачу выполненной:

```bash
curl -X POST http://localhost:8080/api/task/done?id=<ID>
```

Удалить задачу:

```bash
curl -X DELETE http://localhost:8080/api/task?id=<ID>
```

## Запуск тестов

Для тестирования используется директория `tests`.

Настройки подключения к базе находятся в `tests/settings.go`. Пример:

```go
var dsn = "file:local.db?_foreign_keys=on"
```

### Запуск всех тестов

```bash
go test ./tests
```

### Запуск одного теста

```bash
go test -run ^TestDone$ ./tests
```
